# A short Prompt 02 demonstration

Open **Dex > Agent Workbench** with Play stopped. Use a large enough window to show the overview. The signed-in native Codex CLI is already detected on this machine. The Internet and available subscription usage are required for a fresh agent request.

1. Explain the bottleneck: ability interactions require repeatable setup, boundary checks, real source edits and regression verification. Dex automates that loop on a deliberately small, modifiable project.
2. Select **Binding / Arcane Shift**. Read the engineering request. Press **DEMO: INJECT + RUN**. Say explicitly that this developer button injects the known regression before the real agent starts.
3. During investigation, show the actual failing scenarios and generated timing/matchup corpus. The reducer removes irrelevant actions: six original actions become **root -> cast**.
4. The automatic before replay shows Ezreal moving while rooted and spending resources. Codex receives actual simulator feedback and proposes a repair. Show **Source diff**: the C# mobility predicate changes, rather than a UI-only toggle.
5. Show **Compiling**, then **224/224** protected checks. The agent has read-only tools against a limited snapshot and cannot edit the protected oracle or scene checker.
6. The automatic after replay proves root blocks the new blink without spending resources, then expiry restores it. **Passed** requires both core verification and the real arena replay.
7. Optionally repeat with **Rebuttal / hostile missile**. Current-kit Mel's nova must destroy the missile and retaliate; a missile after expiry must still hit. This repairs a different shared predicate through the same workflow.
8. Open the run folder: real model events, source snapshots/diff, assertion results, checker hashes, timeline, screenshots and replay frames. Mention the recorded run's elapsed wall time, with no claim of measured labor saved.

In Play, Esc opens the four-champion practice menu; left-click an enemy once for continuing attacks and aim Q/W/E/R. The kits and arena are simplified. Do not describe the portraits as animated models, or claim exact live-League behavior.

## Network or quota fallback

Use the recordings linked from [current evidence](DexReports/evidence/v2/README.md). Introduce them as **previously recorded real runs**, then inspect their actual diff/results. The offline reference-repair button is a developer recovery tool, never an AI success. An already-repaired source needs the explicitly labeled fixture reset to demonstrate a failure again.

## What remains to measure

The demonstration automates setup, execution, boundary exploration, reduction, patch application, reload continuation and evidence capture. A known expression can also be repaired by a simple scripted reference button. The demo establishes a working checked-agent loop; it does not establish that an LLM is faster than that simpler baseline. The optional human timer records a real manual interval and final verdict, but a controlled engineer comparison is still required for man-hour claims.
